# FarmHub：D2R 离线刷宝便利模组

FarmHub 是《暗黑破坏神 II：狱火重生》（D2R）的离线数据模组，把刷宝时反复要做的操作尽量缩短：开局、传送、找入口、看掉落、整理材料和退出。

- **适配版本：** 国服客户端 build `93854`
- **使用范围：** 仅限离线角色，不要带着数据模组进入战网
- **实现方式：** 只替换游戏数据和界面资源，没有内存读取、DLL 注入或外部运行程序
- **下载：** [最新版本](https://github.com/letianFang/d2_mod/releases/latest)｜[按功能选择历史版本](docs/DOWNLOADS.md)

## 测试中：战斗体能 / 战斗指挥文字提示

移植磨刀门 MDM3C 的战吼提示：战斗指挥（加技能）显示红色 **Skill ↑**，战斗体能（加血）显示红色 **HP ↑**。保留 MDM3C 原有贴图、粒子和位置配置，Skill 在上、HP 在下。佣兵身上同样显示，提示随对应状态持续。

- 原版这两个 buff 的持续光圈换成了这两行文字；吼叫时的施放特效不变。
- 只改高清显示，不改任何数据表，buff 的效果和持续时间不变。
- 怪物身上带这两个状态时也会显示。
- 已替换此前自行绘制的 SKILL/LIFE 版本；本次移植只通过静态检查，显示位置、大小及状态结束后的消失效果仍待进游戏确认。

## 测试中：底材等级

武器和护甲的底材名后面加上一个字的等级：`[普]`、`[扩]`、`[精]`，例如“统治者大盾 [精]”“法师铠 [扩]”。地上、未鉴定、各种品质都会显示。

- 只改物品名称文字（简体中文），不改任何物品数据，也不读取内存。

## 测试中：火蛇显示调整

- 火蛇吐出的火弹改用原版冰弹的青色外观，更护眼。
- 火蛇本体、身上的火焰和地面焦痕在高清画面下不显示。
- 只改高清显示，不改任何数据表：火蛇照样会被召唤，火弹仍是**火焰伤害**，只是看起来像冰弹，注意火抗。
- 火弹命中时的小火花和法师火弹、火焰箭共用，仍是原来的颜色。
- 法师自己的九头蛇用的是同一套火蛇，也会一样显示。
- 经典画面（按 G 切换）不受影响。

## v1.5.0 新增功能

### 符文、宝石、材料合并页

原版的宝石、材料、符文三个堆叠页合并成一个“材料”标签页，全部 91 个堆叠格同屏显示，赫拉迪克方块就在页面中间，不用再来回切页。

- 标签页变为“个人 / 共享 / 材料”。
- 面板保持原版大小，个人和共享仓库的布局与背景都不变。
- 物品仍在原来的堆叠格中，存储方式和堆叠规则没有改动。

### 自动重塑

“材料”页的方块下方有一个勾选框。勾选后约每 0.5 秒执行一次重塑，方便大量合成宝石；取消勾选即停止。

### 隐藏“提取”按钮

查看过往赛季仓库时，“材料”页不再显示“提取”按钮。

> [!WARNING]
> 过往赛季仓库只能取出，赛季结束后会被覆盖。如果里面还有堆叠物品且无法手动取出，把 `bankexpansionlayouthd.json` 中 `withdraw_button` 的 `rect` 改回 `{ "x": 398, "y": 1381 }`，再重新启动游戏。

### 刷宝视野改进

- **恢复尸体显示（国服）：** 启动参数加上 `-assettestmode 1`，死亡墓碑恢复为怪物尸体。
- **隐藏已使用的尸体：** 寻找物品或药水后，尸体随即隐藏，全地图生效；未使用的尸体保持原样。
- **去除面板外侧边框：** 打开装备或属性面板时，外侧露出的区域可以观察和点击场景。

## 安装

1. 从 [Releases](https://github.com/letianFang/d2_mod/releases/latest) 下载 `FarmHub-v1.5.0.zip` 并解压。不要下载 GitHub 自动生成的 `Source code`。
2. 完全关闭游戏，备份角色存档、共享仓库文件和已有的 `mods\FarmHub`。
3. 在解压目录打开 PowerShell，运行校验和安装：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\verify.ps1
   powershell -ExecutionPolicy Bypass -File .\install.ps1 -D2RPath "E:\Diablo II Resurrected"
   ```

4. 在战网的游戏设置中填写启动参数：

   ```text
   -mod FarmHub -txt -assettestmode 1
   ```

5. 启动游戏，选择离线角色。

也可以手动安装：先把游戏目录下已有的 `mods\FarmHub` 移到游戏目录以外，再把压缩包里的 `mods\FarmHub` 复制进去，最终路径应为：

```text
E:\Diablo II Resurrected\mods\FarmHub\FarmHub.mpq\modinfo.json
```

每个发布包都是完整版本，不要叠加安装。

**卸载：** 去掉启动参数，或把 `mods\FarmHub` 移走即可。

## 日常使用

1. 在人物选择页点击中间的角色模型，直接开一局地狱。需要普通或噩梦时，使用原“开始游戏”按钮。
2. 在群魔堡垒打开传送点，选择已解锁的刷宝目的地。
3. 刷完后按 `Esc`，点击菜单按钮以外的空白区域，保存并退出。
4. 重复第 1 步开下一局。

使用时注意：

- 一键进地狱固定选择地狱难度，不会解锁难度；角色必须已经解锁地狱。
- 快速退出没有二次确认。想继续游戏时，请点“返回游戏”或再按一次 `Esc`。
- 修改界面资源或更新模组后，要完全退出游戏再启动，不能只返回人物选择页。

## 存档与兼容性

- `modinfo.json` 使用 `savepath: "../"`，直接沿用原版角色、`Settings.json` 和 `Custom.key`，键位和快速施法设置不会另起一套。
- 模组完整覆盖 `actinfo.txt`、`misc.txt`、`sounds.txt`、`states.txt`、`item-names.json`、高清 `missiles.json` 以及人物选择、暂停菜单、仓库等界面文件。和修改相同文件的其他模组一起使用时，需要手工合并。
- 高清场景类功能（崔凡克视野、入口光柱、方向箭头）只作用于高清画面。

## 游戏更新后

暴雪更新客户端后，不要直接忽略版本不匹配警告，也不要只改版本号。旧数据表和界面文件可能已经与新客户端不兼容，需要以新版原文件为基础重新合并。步骤见[维护文档](docs/MAINTENANCE.md#游戏更新后的必要维护)。
